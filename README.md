# Mini Projects
- [MP1: Cost Estimator for Flights] (https://github.com/aryan-spring2026/oim3640/tree/main/mp1) - helps users understand the cost for international round trips and helps compare 3 different travel destinations. Factors used to derive the calculations include duration of trip (in days), month of travel, and destination of choice. 
- [MP2: DJ Lyric Deck Analyzer] (https://github.com/aryan-spring2026/oim3640/tree/main/mp2) - helps users, particulary DJs, understand which songs best connect with one another by completing an analysis per song entered, comparing 2 songs with each other, and providing a best recommendation for DJS with an order of songs to be added to the deck.
- [MP3: Boston Sports Arena Finder Based on Location] (https://github.com/aryan-spring2026/oim3640/tree/main/mp3) - helps users, particuarly sports fans, with time management with respect to finding which sports arenas are closest to them, providing them with considerable yet crucial factors such as wheelchair accessibility, an interactive map, and top 3 venue locations. The render deployed link is attached within the README.md file in mp3 folder. Attached is a link: https://oim3640-9zlz.onrender.com/
