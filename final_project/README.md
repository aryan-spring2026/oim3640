## What does my project do?
My project was created to help students and young professionals plan for international trips in the most cost effective way. The way that my project does this is by asking the user to input their departing airport, how long they will be staying at their destination, how many people are travelling, and inputting a maximum of three locations to compare and contrast the pricing for each location. This application recommends the most cost-effective method of travel to the user. A weather API key was also added to ensure that the user is aware of potential weather in their respective locatin.

## How to run my project?
For my project to run, I would recommend opening the "app.py" file. This application has all the code for how to run the platform. Once you run the file, it will take you to the "home screen" which welcomes you to the platform and asks you to input your departing location, number of travellers, days staying, and a maximum of three locations internationally that one would like to travel. Afterwards, it will give you a rundown of costs for each location and recommend the most cost-effective location.
