## What does my project do?
My project was created as a tool that helps music performers, in particular DJs, understand which songs are satisifactory to use when composing a deck. When DJs compose decks for their performances, they need to make sure that the songs they use match with one another and curate the same emotion. Therefore, this tool allows you to understand the diversity of an individual song and comparing other songs to give DJs a hollistic overview on whether or not a song works well in a deck or not. Furthermore, it gives you a recommendation on how to order your deck based on the order of songs you would like to include within your deck.

## How to run my project?
For my project to run, I would recommend opening the "POLISH.py" file. This application has all the code for how to run the platform within the terminal. Once you run the file, it will take you to the "home screen" which is the introduction to the platform: the DJ Lyric Deck Analyzer. The application begins with giving a song analysis for the three songs I have used to test this project. Each song has a analysis that includes words, unique words, energy word count, energy label, and describes the main theme based on word selection. Furthermore, it gives a top 10 words list. This is followed by a "Pairwise Based on Song Comparison". This application allows you to compare two songs with one another and provides a recommendation with how strong it is to pair these two songs with each other. To conclude, the application gives you a suggested order to ensure your deck is in alignment with the vibe of your deck.
